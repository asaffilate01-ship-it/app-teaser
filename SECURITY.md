# Security

Please report suspected security or privacy issues privately to `hello@criclume.com`. Do not include
player medical details, junior identities, raw match video, passwords, tokens or payment data in a
GitHub issue.

Include the affected route or service, impact, reproduction steps using non-sensitive test data and a
safe way to contact you. CricLume should acknowledge a valid report within two working days and provide
status updates while it is investigated.
